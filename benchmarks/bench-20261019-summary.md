# Sentinel 当前能力测试简报

日期：2026-10-19。依据最新已完成测试整理，本次未新增实验。

**目前最扎实的能力是WAF请求判定、正常请求代理转发和被动响应头检查。** WAF在完整固定语料上达到平均拦截95%、正常留出误报约5%的目标；主动漏洞扫描覆盖和生产适用性仍缺乏充分验证。

## 1. WAF：固定语料达到目标，召回与误报取得明显改善

被测配置为Sentinel自研SecRule／CRS引擎的 `balanced`，阻断PL4、检测PL4、异常阈值5。默认仍是 `standard`，以下成绩需要显式启用[balanced配置](../examples/waf-balanced.toml)。

| 指标 | 最新结果 | 说明 |
|---|---:|---|
| 正向请求总体拦截率 | **414/434，95.39%** | GoTestWAF语料经本项目适配；重复3次，计数稳定 |
| 21类别等权平均拦截率 | **95.15%** | 所有类别保留在分母中 |
| 原良性语料误报率 | **5/169，2.96%** | GoTestWAF 47段正常文本展开94条请求，加项目75条良性请求 |
| CSIC正常请求回归集误报率 | **316/6,000，5.27%** | 逐条判定与上一版一致 |
| CSIC新增正常留出误报率 | **508/10,000，5.08%** | 策略冻结后首次分类，与回归集无交集 |

相对上一版balanced，类别平均拦截率从87.25%提高到95.15%，多拦31条正向请求，原已拦正向无回退；代价是原良性集新增2条误拦。主要改进为弱信号限额评分、有结构约束的语法检查，以及路径字节处理和规则导出修复。

这些误报率分别按各自集合计算，未合并分母。正向样本已经参与开发，不能把95.15%解释成未知攻击检出率。[原始验收结果](data/20261019/waf95-acceptance.json)、[正常留出结果](data/20261019/csic-waf95-holdout.json)。

## 2. Benchmark来源与证据价值

**本次成绩的含金量在于外部公开语料、上游回归预期、冻结后的正常流量留出，以及真实框架转发验证相互补充。** 以下“证据价值”是依据实际测试范围的判断，不是来源机构对Sentinel的认证或背书。

| 来源／固定版本 | 本项目实际使用范围 | 能说明什么，以及证据边界 |
|---|---|---|
| [Wallarm GoTestWAF](https://github.com/wallarm/gotestwaf)，`8ed7bc21` | 21类、434条正向请求；另取正常文本构造误报对照 | **专项WAF／API测试语料**，提供可追溯的外部检测用例；本次为离线适配，未运行完整官方发送器或全部编码／放置组合，且正向集已用于开发 |
| [CSIC 2010正常请求](https://redata.anii.org.uy/dataset.xhtml?persistentId=doi:10.60895/redata/RWUUSV)，经WebRequests研究数据集公开保存 | 文件ID 389；6,000条回归＋冻结后10,000条留出 | **独立于GoTestWAF的正常HTTP数据**，对识别误报有直接价值；属于历史合成电商流量，留出仍与回归同源，不能代表生产分布 |
| [OWASP CRS官方仓库](https://github.com/coreruleset/coreruleset)，`30cb436b` | 适配上游CRS／go-ftw请求侧规则断言，执行5,046项 | **上游维护的回归预期**，验证规则执行一致性；并非官方go-ftw完整运行，也不是独立于所用规则库的攻击能力评测 |
| [ZAP扩展仓库](https://github.com/zaproxy/zap-extensions)，`15fc3d10` | 选定两个被动规则测试类，12项断言 | **安全扫描工具的规则边界对照**；仅覆盖所选被动行为，未运行完整ZAP扫描 |
| [Mozilla／MDN HTTP Observatory](https://github.com/mdn/mdn-http-observatory)，`c33d9fcc` | 五种响应头的52项断言 | **公开安全配置检查的实现对照**；未执行网站综合评分、TLS、CSP等完整评估 |
| [HTTPWG Structured Field Tests](https://github.com/httpwg/structured-field-tests)，`781ba384` | 839项必需Item用例的接受／拒绝及主token检查 | **协议工作组公开语法测试**，检验解析边界；不覆盖完整类型树、所有容器或漏洞检出 |
| [Web Platform Tests](https://web-platform-tests.org/)，`c47791d6` | 两个选定文件中的22项响应头断言 | **跨浏览器Web平台测试来源**，帮助对齐字段语义；本次没有运行浏览器或验证浏览器执行效果 |
| [Chromium源码测试](https://chromium.googlesource.com/chromium/src/)，`92e02bfa` | 两张Referrer-Policy测试表，执行14项 | **浏览器实现的边界用例**，检查策略选择；不等于完整Chromium安全测试或浏览器行为验证 |
| 本项目[四框架集成脚本](scripts/bench_frameworks.py) | Django 5.2.18、Flask 3.1.3、FastAPI 0.146.0、Express 5.3.0 | **真实运行的代理与后端链路证据**；案例由本项目编写，不是四个框架各自的官方安全benchmark |

公开套件采用固定提交，CSIC固定文件摘要；[复现说明](scripts/README.md)、[CSIC来源摘要](data/20261019/csic-source.json)及[代码和结果哈希](data/20261019/waf95-provenance.json)支持复核。四框架1,080次检查由15种输入×4框架×6条路径×3次重复组成，不是1,080种独立场景；958项定向回归属于项目自身工程测试。

因此，当前证据对**规则与协议实现正确性、所测正常请求兼容性**较有说服力；对**未知攻击泛化、生产误报和同类产品排名**仍不足。没有在相同配置、硬件和语料下对竞品做受控横向测试，不能据来源知名度推导“超过某产品”。

| 验证项 | 最新结果 |
|---|---:|
| Django、Flask、FastAPI、Express完整转发 | **1,080/1,080** |
| 其中代理路径／balanced PL4路径 | **900/900／180/180** |
| 四框架被动响应头断言 | **432/432** |

四框架验证覆盖所选普通请求、后端解析及响应头场景；不代表每个框架分别达到95%攻击拦截率。定向回归排除了主动端到端扫描与slow项。[框架结果](data/20261019/frameworks-waf95.json)、[JUnit](data/20261019/waf95-tests.xml)。

规则兼容性沿用前轮结果：standard CRS适配测试 **5,040/5,046（99.88%）**，另67项未支持。该比例是已执行适配项的通过率，不能视为完整原生ModSecurity兼容或漏洞覆盖率。[兼容性结果](data/20261019/crs-standard-final.json)。

## 4. 扫描器：被动检查有证据，主动覆盖尚不能量化

公开被动检查及协议组件沿用前轮结果：

| 来源／所选适配范围 | 结果 | 范围限制 |
|---|---:|---|
| ZAP被动响应头断言 | 12/12 | 仅选定规则断言 |
| Mozilla Observatory响应头 | 52/52 | 另2项meta未支持 |
| HTTPWG Structured Fields Item | 839/839 | 另759项未执行 |
| WPT响应头 | 22/22 | 仅选定字段测试 |
| Chromium Referrer-Policy | 14/14 | 另1项legacy未支持 |

这些成绩支持所测范围内的配置观察与协议解析能力，不代表完整ZAP规则库或主动漏洞检测覆盖。主动请求参数构造、检测类别和重定向发现仍有未解决项，**目前无法给出可信的主动漏洞覆盖总百分比**。详细来源与缺口见[完整报告§4、§27](bench-20261018-waf-scanner.md)。

## 5. 对当前水平的判断

**项目已具备可复核的WAF防御基准和多框架正常请求集成证据；完整主动扫描能力、未知攻击泛化和生产运行表现仍待验证。** 当前证据不足以宣称达到行业领先水平、可替代成熟产品或已具备通用生产适用性。

仍需重点关注：

- **平均达标不等于所有类别达标。** GraphQL为50%，UserAgent为48.15%；其中部分样本是内省或工具标识，不必然构成攻击。
- **95%尚未获得独立正向验证。** 历史正向子分区类别平均为92.22%，未达95%；该分区也已参与开发。
- **正常留出仍是同源历史流量。** CSIC已分类16,000/36,000条，另20,000条未分类；真实业务误报不能由此保证。
- **吞吐和生产运行尚无本轮新证据。** 本轮没有重测尾延迟、吞吐、长期稳定性或完整原生数据面兼容性。

下一阶段应优先补充独立正向验证集、目标业务正常流量和性能测试，再据证据调整策略。

完整证据见[最新验收汇总](data/20261019/waf95-summary.json)与[完整报告§29](bench-20261018-waf-scanner.md)；设计说明见[改进思路总结](improvements.md)。
